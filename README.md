# app.diyara.ir — CEM/ERP

**Built by Hamidreza Lotfi — 2026**

## Overview

A web-based CRM/ERP application for a retail business, intended to help organise customer relationships and everyday operational processes in one internal system.

## General scenario

- Managing customer records and interactions at a general level
- Supporting day-to-day operational workflows such as orders and follow-ups in general terms
- Role-based access for staff and an overview of business activity
- A responsive internal web interface for desktop and mobile use

This page is a general, anonymous summary only. It deliberately contains no client name, domain, business data, process detail, or other confidential information.
